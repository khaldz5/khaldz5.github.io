# موقع Khaldz — دليل الاستخدام

الموقع كله في ملف واحد: `index.html`.

## إضافة تطبيق أو لعبة جديدة
افتح `index.html` وابحث عن `const WORKS`، ثم انسخ أحد العناصر والصقه تحته وعدّل فيه:

| الحقل | المعنى |
|---|---|
| `type` | `'app'` للتطبيق أو `'game'` للعبة |
| `name` / `desc` | الاسم والوصف بالعربي والإنجليزي |
| `tags` | التصنيفات |
| `rating` | التقييم من 5، أو `null` إذا ما عندك تقييمات حقيقية |
| `version` / `sizeMB` | الإصدار والحجم |
| `url` | مسار ملف APK داخل مجلد `downloads` |
| `soon: true` | يعرض «قريبًا» بدل زر التحميل |

حط ملف APK في مجلد `downloads` باسم إنجليزي بدون مسافات. أقصى حجم للملف في GitHub هو 100 م.ب.

## اسم الموقع والبريد
عدّلهما في `const SITE` أعلى السكربت.
